# BFS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans task-by-task. Do not commit or push unless explicitly requested again.

**Goal:** Recognize declaration-bound BFS and expose bounded graph/FIFO/visited runtime frames.
**Architecture:** Dedicated detector and immutable metadata select JDI projections; trace joins observed snapshots without executing target methods.
**Tech Stack:** Java 17, JavaParser, JDI, Spring Boot, JUnit/AssertJ, Maven.
**Spec:** ../specs/2026-10-20-bfs-design.md (approved by user).

## Global Constraints
- Vertices 0..n-1; int[][] matrix or List<List<Integer>> adjacency list; boolean[] visited.
- Exact ArrayDeque/LinkedList FIFO; visited marked before enqueue, no custom types or aliases not proven safe.
- BEFORE_LOCATION; preserve API constructors and existing algorithms; no dependencies, no external frontend edits.
- Projection at most 100 vertices, 100 queue elements, 1000 edges with bounded nested reads; unknown/truncated must be explicit.
- Trace continuity requires thread/invocation/hint/graph/queue/visited identity; events require unambiguous observed changes.

## Review Focus
- Custom class/import shadowing must not masquerade as JDK collection.
- Graph/queue/visited mutation or reassignment must not preserve false proofs.
- Queue ring wraparound and cyclic linked structures must terminate safely.
- Missing locals/partial snapshots must never fabricate graph edges or completed operations.
- Nested loops and two invocations must not duplicate or mix BFS hints/frames.
