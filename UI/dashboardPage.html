Java Structure Chunker

Dán code Java vào bên trái, bấm phân tích để tách thành từng đoạn theo cấu trúc: package, import, class/interface/enum, method, constructor, field. Bộ phân tích sử dụng AST thật (JavaParser) ở backend, đảm bảo độ chính xác 100% về mặt cú pháp Java.
