Java Structure Chunker

Chọn một file .java, xem trước source, rồi phân tích cấu trúc, tạo AST hoặc chạy JDI để xem biến local tại từng câu lệnh. Backend dùng JavaParser và JDI để map giá trị runtime về đúng AST node.
