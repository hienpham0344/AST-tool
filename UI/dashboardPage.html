Java Structure Chunker

Dán code Java vào bên trái, bấm phân tích để tách thành từng đoạn theo cấu trúc: package, import, class/interface/enum, method, constructor, field. Bộ phân tích dựa trên nhận diện cấu trúc theo brace/regex (không phải trình biên dịch Java đầy đủ), phù hợp cho việc chunk code phục vụ tìm kiếm hoặc RAG.
